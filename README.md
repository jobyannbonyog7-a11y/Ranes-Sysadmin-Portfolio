# System Administrator Career Portfolio
**Developer:** Miel Joy P. Ranes  
**Theme:** Soft pink light mode + low-glare dark mode

## Features
- Responsive design (desktop & mobile)
- Working navigation menu with smooth scroll
- Language translator (English ↔ Filipino)
- Interactive Linux Terminal Simulator
- Amazing animated profile frame with glow, spinning rings & sparkles
- Skill progress bars animation
- Floating sparkle background
- One-click light/dark theme toggle
- Professional pink light theme and soft, readable dark theme

## Sections
1. **Home** – Introduction & navigation
2. **Roles & Responsibilities** – 6 key responsibilities
3. **Technical & Professional Skills** – Skills with progress bars + soft skills
4. **System Administration Tools** – 6 essential tools
5. **Interactive Terminal** – Try Linux commands (help, ls, pwd, whoami, date, neofetch, clear, fortune…)
6. **About the Developer** – Miel Joy P. Ranes profile with special effects

## How to Run
1. Extract the zip
2. Open `index.html` in any modern browser  
   (or use a local server: `python3 -m http.server 8000`)
